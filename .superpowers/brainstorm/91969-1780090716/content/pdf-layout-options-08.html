太陽光提案PDF: レイアウト方向

年間維持費と年間手残りを主要数字に入れる方針で確定。次は2ページPDFの見せ方です。

A. 結論ファースト
1P 結論 / 年間手残り / 利回り / 回収年数
2P 設備概要 / 売電制度 / 維持費 / リスク

A. 結論ファースト

お客様が最初に知りたい結論と数字を前面に出す。営業現場向け。

B. 設備ファースト
1P 発電所概要 / パネル / パワコン / 容量
2P 収益 / 手残り / 費用 / 注意点

B. 設備ファースト

技術資料っぽく堅い。買主が設備を細かく見る場合に強い。

C. バランス型
1P 物件概要 + 主要数字 + 結論
2P 設備詳細 + 費用内訳 + 未確認/リスク

C. バランス型

営業資料らしさと設備資料らしさの両立。今回の推奨案。

推奨: C. バランス型

1ページ目: 発電所名、所在地、販売価格、年間売電収入、年間維持費、年間手残り、想定利回り、回収年数、ひとこと結論

2ページ目: パネル/パワコン、枚数、DC容量、PCS容量、FIT/FIP、売電単価、残存売電期間、連系開始日、稼働年数、入力済み費用内訳、未確認事項
