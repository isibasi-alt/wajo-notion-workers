# 企業マスターDB ページUX設計（タブ構成）＋ WAJO Notion ページUX標準

作成日: 2026-06-07
関連: `2026-06-06-project-page-company-master-tabs-design.md`（案件ページ）

## 背景
深掘りリサーチ(ライン1)で企業マスターのプロパティが増え、「プロパティ爆発」で見づらい。
案件DBと同じ思想（上部に要点＋下にタブ）で整理し、営業が現場で即使える見た目にする。

## WAJO Notion ページUX標準（今後の全DBに共通適用）
1. **ページ上部**に「今すぐ判断に要る要点」＋「実行ボタン」を集約。
2. **下部はタブ**で、目的別に情報を分ける。タブは「見る情報」だけ。操作（作成・成約・失注等）はタブにせず上部ボタン。
3. 詳細データの正本は各専用DBに残し、タブは linked view で「見せる列だけ」表示（プロパティは消さず、見た目で整える）。
4. **タブを分ける軸＝営業の脳の使い方**。商談中に読む「物語(ドシエ)」と、電話する時の「連絡先」は別タブにする。
5. **制約**: Notionのタブ配置・ビュー作成・表示/非表示・並び順は**公開API不可＝UI専用**。設定はNotion UI/Cometで行う。

## 企業マスター タブ構成（確定 v2）

### 📌 ページ上部（常時表示）
- 🏷️ 表示名 / 企業調査ステータス / **信頼度・提案可否** / 🎯 次アクション / 代表者 / 業種 / 担当営業ユーザー
- ボタン: 「AIで企業情報を埋める」「この企業と商談する」「商談準備レポート作成」

### 🗂 タブ
1. **詳細（深掘りドシエ）**: 企業サマリー / 現在課題仮説 / 将来課題仮説 / 営業切り口 / 和上解決策適合 / 3C：顧客・市場 / 3C：競合 / 3C：自社との関係性 / 経営陣 / 役員SNS発信メモ / 直近ニュース / 再エネ接点シグナル / 想定決裁者 / 想定反論・懸念 / 出典ソース ＋ 本文ドシエ
2. **与信・基本情報**: 資本金 / 売上規模 / 従業員規模 / 設立年月 / 上場区分 / 法人番号（TDB） / TDB企業コード / TDB収録業績期 / TDB調査年月日 / 信頼度 / リサーチ最終実行日
3. **連絡先**: 住所 / 住所マップ / 電話番号 / メールアドレス / ウェブサイトURL / X（Twitter） / LinkedIn / 先方担当者 / 面談相手（名前・役職）
4. **商談**（既存）: 関連商談（商談管理DBの linked view: 関連企業 contains この企業）
5. **商談準備レポート**（既存）: 関連商談準備レポート
6. **関連**: 関連名刺 / 関連問い合わせ / 関連案件 / 関連成約 / 顧客接点ログ

## 実行方法
- タブ作成・配置は大ちゃんがNotion UIで実施（layoutはAPI不可）。
- 各ビューの**表示プロパティ選択・並び順**は手作業が大変なため、必要に応じてClaudeがブラウザ自動操作で代行（企業マスターでパイロット → 名刺・案件へ展開）。
- 整備後は [[NOTION_RULES.md]] に従い、プロパティ/DB/ビューを勝手に増やさない（増やすと表示設定が全リセットされるため）。

## 適用ロードマップ
- 企業マスター（本書）→ 名刺DB → 案件DB（既存のため負荷大、将来）。3DB共通で「上部要点＋タブ」に揃える。
