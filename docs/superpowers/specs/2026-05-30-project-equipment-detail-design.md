# 案件起点の発電所設備詳細入力 設計

## 背景

営業資料作成依頼DBへ直接数字や設備情報を入力する運用は、営業マンにとって入力場所が二重になりやすい。中古発電所やブローカー紹介の差し込み案件では、まず案件管理DBに案件を作り、その案件ページ上で発電所情報を入力できることが自然である。

## 採用方針

B案を採用する。

- 案件管理DBは、案件の正本、営業操作盤、資料作成ボタンの入口にする。
- 新しい `発電所設備詳細DB` を作り、案件管理DBと1対1で紐づける。
- 営業資料作成依頼DBは、入力先ではなく、PDF生成ジョブ、作成履歴、出力ファイル、エラーログの置き場にする。

## 企業関係の扱い

案件を紹介してくれる会社と、実際に売りたい会社は分けて扱う。

- `紹介元企業` / `紹介元担当者`: ブローカー、エージェント、紹介会社。企業マスターに登録し、案件管理DBからrelationする。
- `売主企業`: 発電所を売りたい所有者、SPC、事業者。企業マスターに登録し、案件管理DBからrelationする。
- `買主候補企業`: 必要に応じて将来追加する。今回の最小実装では必須にしない。

既存の `関連企業` は互換用に残し、正本入力では `紹介元企業` と `売主企業` を優先する。

## DB構成

### 案件管理DB

案件管理DBには、営業マンが案件一覧や案件ページ上部で見たい項目だけを置く。

- 案件名
- 案件フェーズ / ステータス
- 売買区分
- 提案タイプ
- 販売価格
- 仕入れ価格
- 発電所設備詳細 relation
- 紹介元企業 relation
- 売主企業 relation
- 資料作成依頼 relation
- 提案PDFリンク
- 資料作成メモ

### 発電所設備詳細DB

1案件につき原則1件。案件ページ内にリンクドビューとして表示し、営業マンは案件ページから入力する。

主な入力項目:

- 発電所名
- 所在地 / 発電所住所
- 現場写真
- 電力会社エリア
- 低圧/高圧区分
- パネルメーカー
- パネル型式
- パネル枚数
- DC容量（パネル側kW）
- パワコンメーカー
- パワコン型式
- PCS容量（パワコン側kW）
- FIT/FIP区分
- 売電単価
- 残存売電期間
- 連系開始日
- 年間売電収入
- 月間発電量
- 年間維持費（ランニングコスト）
- O&M費、保険料、地代、固定資産税、除草費、監視通信費、管理費
- 周知方法、質問受付期間、周知日
- 旧認定事業者、新認定事業者、設備ID、認定出力kW
- 発電所所在地画像、ハザードマップ、説明会対象エリア画像、反射光画像

### 営業資料作成依頼DB

営業マンが通常入力するDBではない。Workerが作成する作成ジョブとして扱う。

- 関連案件
- 資料種別
- 作成ステータス
- 不足項目
- 作成メモ
- 提案PDF
- 提案PDFリンク
- 作成日時

案件と設備詳細からコピーした値は、ジョブ時点のスナップショットとして残す用途に限定する。

## Workerの動き

1. 案件ページIDを受け取る。
2. 案件管理DBを読む。
3. 紐づく `発電所設備詳細DB` を読む。
4. 案件側の価格・提案タイプと、設備詳細側の発電所/設備/売電/写真情報を統合する。
5. 足りない項目があれば、営業資料作成依頼DBを作らず `needs-input` で停止する。
6. 不足メッセージは案件側の `資料作成メモ` に返す。
7. 入力が足りていれば、営業資料作成依頼DBに作成ジョブを1件作る。
8. PDF生成後、案件側へ `提案PDFリンク` と `資料作成メモ` を返す。

## 重複防止

- `発電所設備詳細DB` は、同一案件に対して原則1件だけ作る。
- 資料作成依頼は `関連案件 + 資料種別` で重複判定する。
- 同じ案件で `提案書` と `住民説明会資料` は別ジョブとして共存できる。

## 今回の実装範囲

1. 発電所設備詳細DBを作成する。
2. 案件管理DBに `発電所設備詳細`、`紹介元企業`、`売主企業` relationを追加する。
3. Workerの案件資料作成処理を、案件DB + 発電所設備詳細DBを読む形に変更する。
4. 既存の営業資料作成依頼DBは残し、入力先ではなくジョブ履歴扱いに寄せる。
5. テストを追加し、設備詳細DBに値がある場合は資料作成依頼へ引き継がれ、設備詳細がない/不足している場合は案件側で停止することを確認する。

## 非範囲

- Notionテンプレート内の細かいUI配置は、ユーザー側で調整する。
- 買主候補企業の詳細フローは今回作らない。
- 営業資料作成依頼DBの廃止はしない。
