# 2本目の矢＝「当てる弾」の矢筒(quiver)設計（2026-06-08）

> 大ちゃん決定の軸＝**①相手の状況をズバリ当てて驚かす**（"なんで知ってんの"の瞬間が商談を進める）。
> TDB(B)はマネージャー判断の課金奥の手。**それ無しでも"当てる"無料の矢を増やし、A(深掘り)にプラスアルファする。**
> 最終出口＝商太(3体目)が「当てる弾」を"つかみの一撃"に変換。データソース=Notionが大魔神に。

## 当てる弾の矢筒（撃てる順＝驚かせ度×入手性）
1. **再エネ保有・FIT/FIP満了年**（既存=再エネ丸裸/FIT索引）★実証済「2039年満了の出口は？」
2. **補助金採択**（gBizINFO/Perplexity）★最強の新弾「御社〇〇の補助金通ってますよね」＝驚き＋予算/信用の裏取り
3. **調達・入札実績**（gBizINFO）「官公庁案件、実績ありますよね」＝信用・規模
4. **許認可・登録・特許**（gBizINFO）「〇〇の許可お持ちですよね」＝事業の本気度
5. **求人動向**（Perplexity/求人）「今〇〇職を募集＝拡大/人手不足ですね」＝動き時・省力化ニーズ
6. **直近プレス/ニュース**（Perplexity）「先日の〇〇の発表、拝見しました」＝今の関心事
7. **代表の公開発信**（Perplexity・privacy配慮）ラポール用。公開情報のみ・外部送信しない

## 供給アーキ（approach C＝二段）
```
Phase1【今すぐ・無料・キー有】
  A=Perplexity深掘りのクエリに「当てる弾」観点を名指し追加
   (補助金/調達/許認可/求人/プレス/代表発信) → 出典つきで取得
   → 商太の入力 hits[] に渡す → つかみの一撃に変換
Phase2【gBizINFO APIキー届き次第】
  gBizINFOコネクタで 補助金/調達/許認可/財務 を"確報"化
   → Perplexityの当てる弾を裏取り・格上げ(差すだけ)
```

## 商太への接続
- `ShoutaInput` に `hits?: string[]`（当てる弾＝出典つき具体事実の配列）を追加。
- 人格プロンプトに「**つかみは hits の中で最も意外で具体的な一発を使う**」を明記。
- 鉄則：当てる弾は**本当のことだけ・出典つき**。外れ弾は撃たない／不確かは「推測ですが」。代表個人は公開情報のみ。

## 鉄則（和上ルール準拠）
- 量より質。当てて驚かせる"具体"を最優先。
- 出典明示・断定回避・個人情報を外に出さない。
- Notion(3体目=大魔神)に当てる弾を蓄積→「この情報、恐ろしく素晴らしい」を和上の売りに。
