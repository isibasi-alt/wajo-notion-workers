# 投資条件シミュレーションPDF 提出品質化

## 目的

投資条件シミュレーションPDFを、文字崩れのない「経営者が投資判断を読める2ページ資料」として仕上げる。

## 範囲

1. 日本語フォント埋め込みをNotionのPDF表示でも崩れない形へ是正する。
2. 1ページ目は投資判定・主要数値・借入/税効果・判定理由に集中させる。
3. 2ページ目はIRR、NPV、DSCR、減価償却・税効果の固定解説と、当案件で読む意味・前提条件を置く。
4. 提案PDFの設備説明重複と住民説明会ボタンは今回の範囲外とする。

## 完了条件

- ローカル生成PDFにフォント警告・文字化けがない。
- 2ページの文字組みと罫線を画像で確認する。
- `npm run check`、`npm run build`、`npm run test:investment-condition-pdf` が通る。
- デプロイ後、実案件で再生成したPDFをNotion表示で目視確認する。

## 停止線

- デプロイは大ちゃんの明示合図後に `wajo-bs-simulation` から1回だけ行う。
- Notion UI上の最終目視は大ちゃんの操作が必要なため、そこまでを完了と混同しない。
